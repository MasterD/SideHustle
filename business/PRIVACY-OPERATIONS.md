# QuietBatch — first-enquiry privacy operations for owner review

Prepared 29 September 2026. This is a practical draft for the proprietor's compliance framework and personal-information impact review. The owner verifies actual controls and completes information-officer registration; preparing these notes does not certify compliance.

## Defined processing

The first public offer invites a short, requested email conversation about an existing recurring report. There is no upload form, sign-in, analytics script or mailing list. The intended contact data is a name, reply address, business contact details and a description of the report. Use it to answer that request and assess a possible engagement. Do not repurpose it for a campaign.

| Flow | Necessary information | Handling and owner decision |
|---|---|---|
| Public website | Connection information handled by the approved host; fictional report data | Static page, no customer ledger or production files. Public owner contact/location requires specific disclosure approval. |
| Requested enquiry | Reply address, name and report description | Gmail for correspondence. Explain processing in the public notice. Verify account access protection; review provider and cross-border processing terms. |
| Scoping | Authorised, minimised or anonymised sample; input definitions and expected totals | Agree the permitted sample and its transfer/storage/deletion before receipt. Remove identifiers unnecessary for testing. |
| Paid engagement | Agreement, invoice, acceptance and bank receipt evidence | Keep necessary statutory evidence locally with the proprietor's other tax records. Avoid putting bank details in public copy. |
| Production exports | Only data explicitly needed by the agreed report | Separate written processing/confidentiality arrangement, authority from the customer, access and deletion decisions. This step remains outside the initial enquiry process. |

## Owner operating procedure

Before public launch, review the exact seller contact page, the privacy notice, information-officer registration and the PAIA manual. Verify that the selected address can receive legal service. Check actual mailbox/device protections, access permissions and a usable local backup. Publish only the approved static website files, never the ledger, private profile, bank records or regulator documents.

Weekly within the existing owner time budget: review requested enquiries and outstanding commitments, check whether any privacy/access/correction request arrived, and record the response and any lawful retention reason. Unsuccessful enquiries follow the published 90-day deletion plan measured from the last exchange. Do not delete statutory evidence solely because the enquiry period expired.

Before accepting a customer's files, identify whether the proprietor acts as responsible party for the business's own records and operator for customer instructions. Agree the respective duties in writing. Reject unnecessary credentials, payroll or medical records from this pilot. If unexpected sensitive material arrives, restrict access, discuss lawful handling with the sender and document the response.

If an actual security compromise or rights complaint arises, preserve necessary facts, assess the applicable statutory process and use official channels. Do not promise that every incident has the same notification obligation or that a draft procedure proves operational protection. Keep identities and evidence out of public pages and chat.
