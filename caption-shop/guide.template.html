Caption Cleanup Kit 1.0

From subtitles to a clean export.

Open Caption-Cleanup-Kit.html in a current desktop Chrome, Edge or Firefox browser. There is nothing to install. You can disconnect from the internet after downloading the kit.

Try the sample

  1. Click Load sample to see three original example cues.
  2. Choose Plain transcript, then click Run cleanup. The text appears without timing or formatting tags.
  3. Click Download this file. Your source file is never overwritten.

Clean a real file

  1. Choose an SRT or VTT file, or paste its complete contents.
  2. Select the output format. CSV gives one row per cue; timestamped text adds each cue's starting time.
  3. To fix an offset, enter a number of seconds. +1.500 delays every cue by 1.5 seconds. -1.500 advances them. An offset that moves a cue before zero is rejected.
  4. Choose line wrapping if needed. The tool wraps at word boundaries; a single long word can still exceed the target width.
  5. Click Run cleanup, review the checks and download.

Process a batch

Select 2–100 subtitle files with the file chooser. Limits are 2 MB per file and 20 MB for the whole batch. Set the options, run cleanup and choose Export all files as ZIP. The first file supplies the preview. Every file uses the same options.

The ZIP contains converted files and REVIEW.txt. A malformed file stops the entire export and names the problem file, so missing results cannot go unnoticed. Repeated filenames receive numeric suffixes.

What the checks mean

More than 20 non-whitespace characters per second, more than two lines, a line over 42 characters, overlapping cues and cues out of sequence are flagged for review. These are editing prompts, not a guarantee of caption quality or a universal delivery standard.

Compatibility and limits

The kit supports ordinary UTF-8 SRT and WebVTT captions. It regenerates sequential SRT cue numbers. It omits VTT notes, style and region blocks, cue identifiers and positioning settings. It does not support ASS/SSA styling, TTML, embedded media or audio transcription. Plain-text and CSV exports always remove caption markup. Subtitle exports retain markup only when you turn off the formatting-removal option.

Caption Cleanup Kit does not verify speech, spelling, translations, speaker identity or timing against the media. Always review an export in your intended editor or player. Save the original separately.

Privacy

The offline workspace contains no network requests or third-party libraries. Files are read into the page's memory. No history is stored. Downloaded output remains wherever your browser saves it. Close the page or click Clear workspace when finished.
